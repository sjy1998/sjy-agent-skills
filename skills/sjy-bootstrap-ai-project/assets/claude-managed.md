# Implementation Agent Guidance

Before implementation, read `AGENTS.md`, the current approved Spec and Plan,
relevant ADRs, repository status, recent commits, and the active task. Execute
the approved plan task by task, use TDD and verification where applicable, and
keep code, tests, and implementation documentation aligned.

Do not silently change architecture, global interfaces, schemas, technology
choices, high-risk business rules, or the approved plan. Stop and report those
cases for governance or Project Owner approval. Also stop and report a repeated verification failure
or any situation where you cannot reliably determine correctness.
Project-specific role mappings override this default guidance.
